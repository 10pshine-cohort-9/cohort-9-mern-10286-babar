# Notes App

A full-stack Notes Application built using React.js and Node.js.

This project is part of the 10Pearls Shine MERN Internship.

---

## Overview

The application allows authenticated users to:

- Register
- Login
- Create Notes
- Update Notes
- Delete Notes
- Manage their own notes securely

---

## Technology Stack

Frontend

- React.js
- React Router
- Axios
- Tailwind CSS

Backend

- Node.js
- Express.js

Database

- PostgreSQL

Other Tools

- Prisma ORM
- Pino Logger
- Mocha
- Jest
- SonarQube
- Git
