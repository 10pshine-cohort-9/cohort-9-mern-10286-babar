# Notes App

## Overview

A full-stack Notes application built with React and Node.js. Users can register, log in, and manage their personal notes securely.

## Technology Stack

- React.js
- Node.js
- Express.js
- MySQL/PostgreSQL (to be integrated)
- Axios
- React Router
- Pino Logger
- Mocha
- Jest

## Folder Structure

```text
backend/
frontend/
docs/
```

## Prerequisites

- Node.js
- npm

## Installation

### Backend

```bash
cd backend
npm install
```

### Frontend

```bash
cd frontend
npm install
```

## Running

Backend:

```bash
npm run dev
```

Frontend:

```bash
npm run dev
```
